# Security policy

This is a portfolio pattern-and-architecture showcase. `sut/` is a small,
original .NET WinForms sample app written for this repository — it holds no
real user data, no production credentials, and no proprietary or employer code.
`TestCompleteProject/` requires a licensed copy of TestComplete/TestExecute to
run and is not executed in CI.

## Reporting a vulnerability

If you find a real security issue in this repository (for example, a dependency
with a known CVE, or a way the sample app or scripts could be misused), please
open a [GitHub issue](../../issues/new) or email
**shahbazhanif87@gmail.com**. There is no bug bounty; this is a demonstration
project, but reports are still welcome and will be looked at.

## Supported versions

This repository tracks `main` only; there are no maintained release branches.
